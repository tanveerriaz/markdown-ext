🛠️ Setup guide

Pick your browser below. Download the zip once — it includes the extension/ folder for Chrome and Edge.

Chrome / Edge / Brave · Firefox · Full guide

Chrome / Edge / Brave

1. Download and unzip

Click Download zip above. Open markdown-ext/extension/ — that folder contains manifest.json.

2. Enable Developer mode

Open chrome://extensions and turn on Developer mode (top-right).

3. Load unpacked

Click Load unpacked and select markdown-ext/extension.

4. Convert any page

Visit a page, open the extension, click Convert, then copy or download Markdown.

Tip: On some Chrome versions you can drag the extension folder onto chrome://extensions.

Firefox

Use about:debugging, not about:addons. Installing from the Add-ons page or double-clicking .xpi shows “appears to be corrupt” on release Firefox. Load a temporary add-on from the debugging page only.

1. Download and unzip

Click Download zip above. You need markdown-ext/extension/manifest.json (the .xpi in the zip is optional — load it only from the same debugging dialog).

2. Open about:debugging

In the address bar, open about:debugging → This Firefox → Load Temporary Add-on…

3. Select manifest.json

Set the file picker to All Files, open markdown-ext/extension/, and select manifest.json.

4. Convert any page

Visit a page, open the extension, click Convert, then copy or download Markdown.

Tip: Grayed files? Use All Files in the picker. “Corrupt” error? You opened about:addons — use about:debugging instead. The add-on is removed when you fully quit Firefox.
