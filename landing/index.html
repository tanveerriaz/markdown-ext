Chrome / Firefox Extension

Markdown Convert

Convert any webpage into clean, copyable Markdown in one click.

Download ZIP View on GitHub

What it does

Click Convert to extract the page content, strip common clutter (nav/footer/scripts/styles), and generate a Markdown preview you can copy or download.

Install (Developer mode)

  1. Download markdown-ext.zip and unzip it.
  2. Open chrome://extensions and enable Developer mode.
  3. Click Load unpacked and select the extension/ folder.

Tip: On some Chrome versions you can also drag the unzipped folder into chrome://extensions.
