Markdown Convert — quick install
================================

Chrome / Edge / Brave
---------------------
1. Unzip this archive.
2. Open chrome://extensions → enable Developer mode.
3. Load unpacked → select the "extension" folder (contains manifest.json).

Firefox
-------
1. Unzip this archive.
2. Open about:debugging → This Firefox → Load Temporary Add-on.
3. Either:
   - Select extension/manifest.json (set file picker to "All Files"), OR
   - Select markdown-ext.xpi from this folder.

Note: Firefox temporary add-ons are removed when you fully quit the browser.

Full guide: https://github.com/tanveerriaz/markdown-ext/blob/main/docs/SETUP.md
